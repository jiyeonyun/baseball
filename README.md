# 윤지연 포트폴리오

프론트엔드 개발자 윤지연의 포트폴리오 웹사이트입니다.

## 기술 스택

-   Next.js 15
-   React 19
-   TypeScript
-   Tailwind CSS
-   Framer Motion
-   React Icons

## 기능

-   다크모드 지원
-   반응형 디자인
-   인터랙티브 프로필
-   GitHub 기여도 차트
-   오디오 플레이어
-   프로젝트 및 경력 정보

## 로컬 개발

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 배포

이 프로젝트는 GitHub Pages에 자동으로 배포됩니다.

-   `main` 브랜치에 푸시하면 자동으로 배포됩니다
